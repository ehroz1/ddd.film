# Киносвайп

Одностраничный сайт: свайпайте карточки фильмов из афиши (вправо — «Интересно», влево — «Нет», вверх — «Может быть»), смотрите трейлеры и делитесь подборкой в Telegram.

Сайт: https://ehroz1.github.io/ddd.film/

## Структура

- `index.html` — всё приложение (разметка, стили, скрипт и список фильмов в константе `F`).
- `posters/` — локальные копии постеров. Они подставляются, если внешняя картинка не загрузилась, и используются для скриншота результата.

## Как обновить афишу

Отредактируйте массив `const F=[...]` в `index.html`. Поля фильма:

- `t` — название, `g` — жанр, `c` — актёры и режиссёр, `d` — описание, `dt` — дата, `age` — возраст;
- `kp` — ID фильма на Кинопоиске (по нему грузится постер в высоком качестве);
- `lo` — запасной постер, `emb` — путь к локальному постеру;
- `hi` — широкий кадр с afisha.uz (показывается в ленте кадров);
- `yt` — список ID русских трейлеров на YouTube (первый открывается по умолчанию, из него же берутся кадры);
- `en` — ID оригинального трейлера (только как источник дополнительных кадров).
